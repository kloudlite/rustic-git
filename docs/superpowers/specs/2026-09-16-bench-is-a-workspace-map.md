- `crd::Bench` (`crates/workspaces/src/crd/bench.rs`): cluster-scoped, `selectable=.status.nodeName`. No region/name/storage/packages/locks. Status: phase, nodeName, podRef, idleSince, conditions. Status: phase, observedGeneration, nodeName, volumeRef, podRef, conditions, packages, sshHostKey, head. `Phase` enum already has `Starting` and `Idle`.
