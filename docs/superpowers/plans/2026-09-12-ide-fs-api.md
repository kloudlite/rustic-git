# Workspace state API (`/fs/*`) — implementation plan

**Spec:** `docs/superpowers/specs/2026-09-12-ide-fs-api-design.md` · **Crate:** `crates/ide`

## Global constraints

- Every path through `paths::confine(root, home, p)`; a refusal is 403 `{"error"}`.
- git via the `git` binary only, `current_dir(root)`, `tokio::time::timeout(10 s)`; not a repo ⇒ `repo: false`, never an error.
- One git process per request, never per entry.
- Every GET carries `ETag`; `If-None-Match` ⇒ 304.
- Caps: depth 1..3 (400), 5 000 entries, file 10 MiB (413), diff 200 000 bytes (truncated).
- Not tools: nothing here enters the `Registry`; `GET /tools` does not list them.
- Files under ~800 lines: `fs/mod.rs` (routes + etag), `fs/git.rs` (porcelain, numstat, show, diff), `fs/tree.rs` (walk, stat, roll-up).

## Task 1: `fs/git.rs`

```rust
pub struct Status { repo: bool, branch: Option<String>, head: Option<String>, upstream: Option<String>, ahead: u32, behind: u32, changes: Vec<Change>, ignored: Vec<String> }
pub struct Change { path: String, index: char, worktree: char, renamed_from: Option<String> }
pub fn parse_porcelain_v2(bytes: &[u8]) -> Status                 // pure
pub async fn status(root: &Path, with_ignored: bool) -> Result<Status, String>  // --porcelain=v2 --branch -z [--ignored=matching]
pub async fn numstat(root: &Path) -> Result<Vec<(String, Option<(u32,u32)>)>, String>  // git diff --numstat HEAD; None = binary
pub async fn show(root: &Path, at: &str, rel: &str) -> Result<Option<Vec<u8>>, String>  // git show at:rel; 128 exit ⇒ None
pub async fn diff(root: &Path, rel: Option<&str>, against: Against, untracked: bool) -> Result<(String, bool /*binary*/), String>
pub async fn stash_count(root: &Path) -> u32
async fn git(root, args) -> Result<Output, String>   // timeout 10 s, "not a git repository" detected by exit 128 + stderr
```

`Against::Head` ⇒ `git diff HEAD -- rel`; `Index` ⇒ `git diff -- rel`; `Staged` ⇒ `git diff --cached -- rel`. Untracked ⇒ `git diff --no-index -- /dev/null rel` (exit 1 is success there). Binary detected by `Binary files … differ`.

Tests: fixture porcelain strings (branch, modified `1 .M`, untracked `? x`, rename `2 R.` with NUL second path, detached); numstat `-\t-` ⇒ None; a tempdir repo: `show HEAD:a.txt`, `diff` of a modified and an untracked file, not a repo ⇒ `repo:false`.

## Task 2: `fs/tree.rs`

```rust
pub struct Entry { name, kind: &'static str, size: u64, mtime: u64, ignored: bool, git: String, target: Option<String>, entries: Option<Vec<Entry>> }
pub async fn tree(root, home, path, depth) -> Result<(PathBuf, Vec<Entry>, bool), ToolError>
pub async fn stat(root, home, path) -> Result<Option<(Entry, Option<String> /*mime*/)>, ToolError>
```

- `read_dir` in `spawn_blocking`, dirs first then byte-order names, recurse to `depth`, stop at 5 000.
- One `git::status(root, true)` per request; index changes by path; letter per entry (worktree col, else index col, `?` untracked); directory roll-up (`M` any dirty below, `?` all untracked); `ignored` from status's `!` rows (`--ignored=matching` lists ignored files and whole ignored dirs), `.git` forced.
- `mime` reuses `tools::files`'s sniff (`pub(crate)`).

Tests: tempdir repo with `.gitignore` containing `.cache/`; order; `.cache` ignored, `.git` ignored; dirty roll-up onto `src`; symlink target; depth 2 nesting; depth 0 and 4 refused (400 via `ToolError::Invalid`); not a repo ⇒ all `ignored:false`, `git:""`.

## Task 3: `fs/mod.rs` routes

`GET /fs/tree`, `/fs/stat`, `/fs/file`, `/fs/git`, `/fs/changes`, `/fs/diff` with `Query<…>` structs. Shared `fn etag_of(&[u8]) -> String` (fnv/xxhash from std `DefaultHasher` is enough — ponytail), `fn conditional(headers, etag, body) -> Response` answering 304. `/fs/file`: `tokio::fs::metadata` first for the weak etag `"{len}-{mtime_ns}"` and the 413, then read; `at=` path goes through `git::show`. Errors: move `status_of(&ToolError)` from `api.rs` into `tools/mod.rs` and use it here.

`server.rs`: six routes; `lib.rs`: `pub mod fs;` and the module map. Route tests: 200 tree, 304 on repeat, 400 depth, 403 outside, 404 stat and file, 413 (a 10 MiB + 1 file), `/fs/git` on a plain tempdir ⇒ `repo:false`, `/fs/diff` of a modified file contains `@@`.
