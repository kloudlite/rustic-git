# User Keys Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** SSH and signing keys belong to the person; the git tier verifies membership at use; workspaces get one `OwnerKeys` projection per owner that the agent converges, with a status.

**Architecture:** The directory (Cosmos, behind `bins/api`) is the only place a key is created or removed. `bins/server` maps a fingerprint to the person and checks team membership per request through the directory it already connects to. `bins/api` writes a cluster-scoped `OwnerKeys` CR per owner (union of the members' keys) with server-side apply, on change and on a resync beat; `bins/agent` watches it and writes `{pool}/keys/{owner}/authorized_keys` in place, mounted into pods as a hostPath `type: File`, and reports `Synced`.

**Tech Stack:** Rust (axum, kube-rs, russh, mongodb), Next.js web, the SLO probe.

**Spec:** `docs/superpowers/specs/2026-09-07-user-keys-design.md`

## Global Constraints

- Every command runs in the `dev` pod at `/work/src` (`deploy/dev/exec.sh` or a script piped into `kubectl exec -i`); nothing runs on the laptop.
- Gate before every commit: `cargo clippy --workspace --all-targets -- -D warnings` and the tests named in the task. `deploy/k3s/crds.yaml` is regenerated with `CRD_REGEN=1 cargo test -p kloudlite-workspaces --test crd_yaml`, never hand-edited.
- Fail closed everywhere: a directory error refuses; a missing or empty `OwnerKeys` writes an EMPTY `authorized_keys` and `Synced=False`; never an accepted key that the list does not show.
- The cluster never authors a key. Only `bins/api` writes `OwnerKeys.spec`; the agent patches `/status` only (RBAC + admission policy).
- Rollout order: server tier → agents → api. Every task keeps the previous state working.
- Comments explain why. Commit subjects imperative sentence case, no tool attribution.
- Directory identity for a person is the lowercased email (`User.email`); the handle is `User.username`.

In `crates/app/src/lib.rs`, in `impl App`:

```rust
/// May `user` (an email) act under `owner` (a handle)? Their own handle, or a team they belong
/// to. `Err` when the directory is configured but cannot answer — the caller refuses, never
/// falls open. With no directory at all (single-node, `Source::Absent`) only the user's own
/// handle matches, and "own handle" is then the fingerprint row's value itself: a solo deploy
/// registers keys by handle and has no memberships to check.
pub async fn may_act(&self, user: &str, owner: &str) -> Result<bool> {
    match &self.dir {
        kloudlite_pulls::pulls::Source::Absent => Ok(user == owner),
        kloudlite_pulls::pulls::Source::Unavailable => Err(crate::err("directory unavailable")),
        kloudlite_pulls::pulls::Source::Directory(d) => {
            let (cached, at) = { self.membership.lock().unwrap_or_else(|e| e.into_inner()).get(&(user.to_string(), owner.to_string())).cloned().unzip() };
            if let (Some(yes), Some(at)) = (cached, at) {
                if at.elapsed() < MEMBERSHIP_TTL { return Ok(yes); }
            }
            let own = d.user(user).await.map_err(|e| crate::err(&format!("directory: {e}")))?
                .is_some_and(|u| u.username.as_deref() == Some(owner));
            let yes = own || d.is_member(user, owner).await.map_err(|e| crate::err(&format!("directory: {e}")))?;
            let mut m = self.membership.lock().unwrap_or_else(|e| e.into_inner());
            if m.len() >= MEMBERSHIP_CAP { m.clear(); }
            m.insert((user.to_string(), owner.to_string()), (yes, std::time::Instant::now()));
            Ok(yes)
        }
    }
}
```

```rust
/// One line per distinct access key across `sets`, sorted. Lines without material (keys added
/// before it was kept) are skipped, as `authorized_keys_lines` skips them.
pub fn authorized_keys_union(sets: &[&[Credential]]) -> String {
    let mut lines: Vec<&str> = sets.iter().flat_map(|s| s.iter()).map(|c| c.material.trim()).filter(|m| !m.is_empty()).collect();
    lines.sort_unstable();
    lines.dedup();
    lines.iter().map(|l| format!("{l}\n")).collect()
}
```

```rust
/// The `authorized_keys` file for an owner namespace: a person's own keys, or every member's
/// keys for a team. Keys belong to people; a namespace only ever sees a projection.
pub async fn authorized_keys_for(db: &kloudlite_pulls::directory::Directory, owner: &str) -> Result<String> {
    if let Some(u) = db.user_by_handle(owner).await? {
        let keys = db.credentials_for(&u.email, CredentialKind::SshKey).await?;
        return Ok(crate::credentials::authorized_keys_union(&[&keys]));
    }
    let Some(team) = db.get(owner).await? else { return Ok(String::new()) };
    let mut sets = Vec::with_capacity(team.members.len());
    for m in &team.members {
        sets.push(db.credentials_for(&m.user, CredentialKind::SshKey).await?);
    }
    let refs: Vec<&[Credential]> = sets.iter().map(|s| s.as_slice()).collect();
    Ok(crate::credentials::authorized_keys_union(&refs))
}
```

```rust
/// One owner namespace's `authorized_keys`, PROJECTED from the directory: keys belong to people,
/// a namespace sees the union of its members' keys. Cluster-scoped, named by the owner handle,
/// written only by `bins/api` (server-side apply, on every key or membership change and on a
/// resync beat), read by every node's agent, which converges it into the file its pods mount
/// and reports `Synced`. Never the record: deleting it locks the owner out until the next beat
/// rewrites it, and nothing in a cluster can add a key.
#[derive(CustomResource, Clone, Debug, PartialEq, Serialize, Deserialize, JsonSchema)]
#[kube(
    group = "kloudlite.io",
    version = "v1alpha1",
    kind = "OwnerKeys",
    plural = "ownerkeys",
    shortname = "ok",
    status = "OwnerKeysStatus",
    printcolumn = r#"{"name":"Generation","type":"integer","jsonPath":".spec.generation"}"#,
    printcolumn = r#"{"name":"Synced","type":"string","jsonPath":".status.conditions[?(@.type==\"Synced\")].status"}"#,
    derive = "PartialEq"
)]
#[serde(rename_all = "camelCase")]
pub struct OwnerKeysSpec {
    /// The directory's version of this set: monotonic, so a reader can tell "same bytes,
    /// rewritten" from "changed". Unix millis at the api's write.
    pub generation: i64,
    /// The file, verbatim: one OpenSSH public line per key, sorted, `\n`-terminated. Empty is a
    /// namespace whose members have no keys — written as an empty file, never skipped.
    #[serde(default)]
    pub authorized_keys: String,
}

#[derive(Clone, Debug, Default, PartialEq, Serialize, Deserialize, JsonSchema)]
#[serde(rename_all = "camelCase")]
pub struct OwnerKeysStatus {
    #[serde(default, skip_serializing_if = "Option::is_none")]
    pub observed_generation: Option<i64>,
    #[serde(default, skip_serializing_if = "Vec::is_empty")]
    pub conditions: Vec<Condition>,
}

/// `OwnerKeys` condition: this node has written `spec.generation` to the file its pods mount.
pub const KEYS_SYNCED: &str = "Synced";
```

```rust
//! `OwnerKeys` → the file sshd reads. The projection is the api's; this node's whole job is to
//! make the bytes on disk equal the spec and say so in status.

use std::sync::Arc;
use kube::{Api, ResourceExt};
use kloudlite_workspaces::{crd, k8s};
use super::{status::patch_status, Ctx};

/// In place, never by rename: pods hold the inode through their hostPath mount.
pub fn write_keys_file(pool: &str, owner: &str, contents: &str) -> std::io::Result<()> {
    use std::io::Write;
    use std::os::unix::fs::{OpenOptionsExt, PermissionsExt};
    let path = k8s::keys_file(pool, owner);
    std::fs::create_dir_all(std::path::Path::new(&path).parent().unwrap())?;
    let mut f = std::fs::OpenOptions::new().write(true).create(true).truncate(true).mode(0o600).open(&path)?;
    f.write_all(contents.as_bytes())?;
    f.sync_all()?;
    std::fs::set_permissions(&path, std::fs::Permissions::from_mode(0o600))?;
    // sshd reads the file as the login user (`kl`, uid 1000), through StrictModes off; the uid is
    // what lets the read succeed at all.
    std::os::unix::fs::chown(&path, Some(k8s::SSH_UID as u32), Some(k8s::SSH_UID as u32))?;
    Ok(())
}

async fn converge(ctx: &Ctx, api: &Api<crd::OwnerKeys>, obj: crd::OwnerKeys) {
    let owner = obj.name_any();
    let gen = obj.spec.generation;
    let prev = obj.status.as_ref().and_then(|s| s.conditions.iter().find(|c| c.type_ == crd::KEYS_SYNCED));
    let (ok, reason, msg) = match write_keys_file(&ctx.pool, &owner, &obj.spec.authorized_keys) {
        Ok(()) if obj.spec.authorized_keys.is_empty() => (true, "NoKeys", "no member has a key; nobody is admitted"),
        Ok(()) => (true, "Applied", "written to this node's keys file"),
        Err(e) => { tracing::warn!(%owner, error = %e, "keys.write.failed"); (false, "WriteFailed", "could not write this node's keys file") }
    };
    let status = serde_json::json!({
        "observedGeneration": if ok { Some(gen) } else { None },
        "conditions": [crd::condition_since(prev, crd::KEYS_SYNCED, ok, reason, msg, gen)],
    });
    if let Err(e) = patch_status(api, &owner, "OwnerKeys", status).await {
        tracing::warn!(%owner, error = %e, "keys.status.failed");
    }
}

/// Every `OwnerKeys` in the cluster, converged on every event and on a ten-minute tick — the
/// tick is what heals a file deleted by hand or a write that failed transiently.
pub async fn run(ctx: Arc<Ctx>) {
    use futures::StreamExt;
    use kube::runtime::{watcher, WatchStreamExt};
    let api: Api<crd::OwnerKeys> = Api::all(ctx.client.clone());
    let mut events = std::pin::pin!(watcher(api.clone(), watcher::Config::default()).default_backoff().applied_objects());
    let mut tick = tokio::time::interval(std::time::Duration::from_secs(600));
    tick.set_missed_tick_behavior(tokio::time::MissedTickBehavior::Delay);
    loop {
        tokio::select! {
            event = events.next() => match event {
                Some(Ok(obj)) => converge(&ctx, &api, obj).await,
                Some(Err(e)) => tracing::warn!(error = %e, "keys.watch.failed"),
                None => return,
            },
            _ = tick.tick() => {
                if let Ok(list) = api.list(&Default::default()).await {
                    for obj in list.items { converge(&ctx, &api, obj).await; }
                }
            }
        }
    }
}
```

```rust
//! only here. Two triggers, one function: a key or membership change projects the owners it

use std::sync::Arc;

pub const KEYS_RESYNC_SECS: u64 = 300;

pub fn owner_keys(owner: &str, generation: i64, authorized_keys: String) -> crd::OwnerKeys {

/// Project ONE owner. A failed directory lookup writes nothing (the last projection stands, and
/// the beat retries); an owner with no keys writes an EMPTY file, which is the truth.
pub async fn project(s: &ApiState, owner: &str) -> Result<(), String> {
    let (Some(c), Some(dir)) = (s.kube.as_ref(), s.directory.as_ref()) else { return Ok(()) };
    let Some(file) = dir.authorized_keys_for_owner(owner).await else {
        return Err(format!("could not read {owner}'s keys"));
    };
    let gen = std::time::SystemTime::now().duration_since(std::time::UNIX_EPOCH).map(|d| d.as_millis() as i64).unwrap_or(0);
    let api: Api<crd::OwnerKeys> = Api::all(c.clone());
    api.patch(owner, &PatchParams::apply("kloudlite-api").force(), &Patch::Apply(&owner_keys(owner, gen, file)))
        .await
        .map(|_| ())
        .map_err(|e| format!("writing OwnerKeys/{owner}: {e}"))
}

/// Every owner that has a namespace in this region — the owner label is what the controller
/// stamps, so a team the api never heard of is still covered.
pub async fn project_all(s: &ApiState) {
    let Some(c) = s.kube.as_ref() else { return };
    let api: Api<k8s_openapi::api::core::v1::Namespace> = Api::all(c.clone());
    let sel = format!("{}=workspace", crate::k8s::KIND_LABEL);
    let Ok(list) = api.list(&kube::api::ListParams::default().labels(&sel)).await else { return };
    let mut owners: Vec<String> = list.items.iter().filter_map(|n| n.metadata.labels.as_ref()?.get(crate::k8s::OWNER_LABEL).cloned()).collect();

    for o in owners {
        if let Err(e) = project(s, &o).await { tracing::warn!(owner = %o, error = %e, "keys.project.failed"); }
    }
}

    tick.set_missed_tick_behavior(tokio::time::MissedTickBehavior::Delay);

}
```
